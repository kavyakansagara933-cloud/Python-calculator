# Python Calculator

A command-line calculator built with Python. This project was created to practice Python fundamentals, error handling, code organization, automated testing, and Git/GitHub.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Division-by-zero handling
- Invalid input handling
- Repeated calculations
- Calculation history
- Operator-based interface
- Automated tests using pytest

## Technologies Used

- Python 3
- pytest
- Git
- GitHub
